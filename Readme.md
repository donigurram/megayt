# MegaYT

MegaYT is a YouTube clone developed to replicate the core functionality and user experience of YouTube. This project focuses on building a responsive and modern video streaming interface while improving frontend development skills.

## Features

- Responsive user interface
- Home page with video listings
- Video playback page
- Search functionality
- Clean and intuitive layout

## Tech Stack

- HTML
- CSS
- JavaScript

## Getting Started

### Clone the Repository

```bash
git clone https://github.com/donigurram/megayt.git
```

### Navigate to the Project Directory

```bash
cd megayt
```

### Install Dependencies

```bash
npm install
```

### Run the Development Server

```bash
npm run dev
```
